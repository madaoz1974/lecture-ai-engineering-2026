# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の `app.ask`（素のLLM）では講座固有の用語集を参照できないため、一般論で推測して回答（ハルシネーション）するか「分からない」と答えていましたが、今回のエージェントは回答前に `search_glossary` ツールで `data/glossary.json`（`homework-levels`）を検索するため、「基礎・実装・発展の3つのレベルがあり、どれか1つに取り組めば完了」という講座の正確な定義に基づいて回答できていました。
- `--trace` で見えたツール呼び出し（ツール名と引数）：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`
- 1つの質問での LLM 呼び出し回数（`requests`）：3回（①最初の質問を受けてどのツールを呼ぶか決める呼び出し、②ツールから返ってきた検索結果を読んで追加検索や回答方針を決める呼び出し、③最終的な回答文を生成する呼び出し）
- 追加したツールと、docstring に書いた説明：
  - 追加したツール：`make_quiz(lecture: int) -> str`
  - docstring に書いた説明：`指定された回（lecture）の用語集から、確認問題を1問作成して返します。ユーザーから特定の回の確認問題を出してほしいと頼まれた場合に使用してください。`

## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/agent.py` の `INSTRUCTIONS` から「`- 用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。`」の1行を削除し、同じ質問（`"LoRAとQLoRAの違いは？"` および `"AIE2026の講座の宿題にある「3レベル」とは何ですか？"`）を `--trace` 付きで実行して、変更前とツールの呼ばれ方・回答を比較した。
- 結果：
  - `"LoRAとQLoRAの違いは？"` のように一般的なAI用語の質問では、`INSTRUCTIONS` から必須指示を消すと `search_glossary` が1回も呼ばれなくなり（`requests=1`）、モデル自身の事前学習知識だけで回答するようになった。また、用語集を引かないため回答末尾の「関係する回（第2回）」も正しく示せなくなった。
  - 一方、`"AIE2026の講座の宿題にある「3レベル」とは何ですか？"` のように講座固有であることが明らかな質問では、`search_glossary` の docstring 側に「この講座（AIE2026）に固有の言葉について答える前に使うこと」と書かれているため、`INSTRUCTIONS` の行を消してもツールが呼ばれた。
- 気づき・疑問：エージェントがツールを使うかどうかは、`INSTRUCTIONS`（システムプロンプト全体の指示）と各ツールの `docstring`（ツールの説明文）の両方に影響されることが分かった。モデルが「自分の知識で答えられる」と判断しがちな一般的な用語でも、講座固有の定義や扱う回（第N回）を正確に答えさせたい場合は、`INSTRUCTIONS` 側で「必ず確認する」と強く制約をかける必要があると感じた。
